# Kill to the Kiss

Fabric weapon mod for Minecraft 1.21. AK-47, M16, UZI, Sniper Rifle and USP with magazines,
ammo, reload animations, recoil and full crafting support.

## Install
Drop `build/libs/kill-to-the-kiss-1.0.0.jar` plus Fabric API into `.minecraft/mods`.

## Controls
- Right click: fire (hold for full-auto on AK-47, M16, UZI)
- `R` or Sneak + Right click: reload (takes matching ammo from inventory)
- Sneaking tightens spread, sprinting widens it

## Crafting
| Item | Recipe (I iron, N nugget, G gunpowder, P planks, R redstone, B barrel, S stock, C receiver) |
|---|---|
| Gun Barrel | I diagonal (3 iron ingots) |
| Gun Receiver | ring of 8 iron around 1 redstone |
| Gun Stock | `PPP / PP  / P  ` |
| Pistol Ammo ×8 | `N / G` |
| Rifle Ammo ×8 | `N / N / G` |
| Sniper Ammo ×4 | `I / N / G` |
| AK-47 | `  B / SCP /  I ` |
| M16 | `  B / SCI /  I ` |
| UZI | `ICB /  I ` |
| Sniper | `GBB / SCB /  I ` (G = glass) |
| USP | `CB /  I` |

## Build
```
./gradlew build
```
Assets are generated by `python3 tools/gen_assets.py` (needs Pillow).
